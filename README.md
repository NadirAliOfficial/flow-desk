# FlowDesk

A real-time trading dashboard that surfaces Discord trade alerts alongside interactive candlestick charts.

## Features

- Live alert card — ticker, price level, %, Float, RVol, Vol, IO, MC, SI, Theme, flags (NHOD / Halted / High CTB / Reg SHO)
- Latest Alerts watchlist with instant chart switching
- Candlestick chart with MA20 overlay and 8 timeframes (1D → All)
- Volume histogram panel
- Dark theme with gold accents

## Stack

- Vanilla HTML / CSS / JS
- [Lightweight Charts](https://github.com/tradingview/lightweight-charts) by TradingView
